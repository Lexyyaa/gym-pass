백엔드 과제: 헬스장 회원권 관리

개요

헬스장 운영자가 회원과 회원권을 관리하고, 회원의 출입을 기록하며, 회원권 만료 전 안내를 발송하는 서비스의 백엔드를 구현합니다.

* 제한 시간 3시간, AI 도구 사용 자유
* 지점 200곳, 회원 10만 명 규모
* 필수 요구사항을 모두 구현하기 어려울 수 있습니다. 구현 범위와 우선순위도 평가에 포함됩니다.

기술 조건

* Java 17 이상, Spring Boot 3.x, Spring Data JPA, MySQL
* Docker Compose로 실행 가능
* 인증 미구현. 요청 헤더로 지점을 식별하며 다른 지점 데이터 접근은 거부
* REST API로 설계하고 API 명세를 README 또는 별도 문서에 기재
* 요구사항 중 정의가 필요한 부분은 직접 가정하고 README에 근거를 기재

외부 연동

```java
public interface MessageClient {
    SendResult send(String phone, String text);
}
```

* 응답 지연 100~500ms, 일부 요청은 실패 응답
* 가짜 구현체를 작성하고 지연·실패 비율을 설정값으로 조절 가능해야 함

필수 요구사항

1. 회원과 회원권

* 회원 등록: 이름, 연락처
* 회원권 등록: 회원, 종류(기간제 또는 횟수제), 시작일, 기간(개월) 또는 횟수, 결제 금액
* 한 회원은 같은 시점에 유효한 회원권을 하나만 가질 수 있음
* 회원권 종류는 추후 추가 예정

2. 출입

* 회원 출입 기록. 유효한 회원권이 있어야 출입 가능
* 횟수제는 출입 시 1회 차감
* 같은 회원이 하루에 여러 번 출입해도 횟수는 하루 1회만 차감

3. 정지와 연장

* 회원이 회원권을 일정 기간 정지할 수 있음. 정지 기간만큼 종료일이 연장됨
* 정지 가능 횟수와 기간에는 상한이 있음. 상한은 직접 정의
* 정지 중에는 출입 불가

4. 만료 안내

* 회원권 만료 7일 전과 당일에 안내 메시지 발송
* 횟수제는 잔여 3회일 때 안내
* 매일 09:00에 자동 실행
* 발송 실패 건은 재시도. 상한은 직접 정의

5. 조회

* 지점의 회원권 목록. 상태(유효, 정지, 만료)별 필터, 만료 임박 순 정렬
* 회원 한 명의 출입 이력과 회원권 변경 이력

검증 요구

* 같은 회원의 동시 출입 요청 테스트
* 정지·연장 날짜 계산 파라미터 테스트 (월말, 2월 포함)
* 만료 안내 대상 선정 테스트 (경계일 포함)
* 회원권 목록 조회 쿼리 실행 계획과 인덱스 설계 근거
